# Security Policy

## Supported versions

CropAI PK is an actively developed project. Security fixes are applied to the latest
code on the `main` branch. Please make sure you are running the most recent version
before reporting an issue.

| Version        | Supported |
| -------------- | --------- |
| `main` (latest)| Yes       |
| older commits  | No        |

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report it privately by email:

- **contact@abdullahawais.com**

Include as much of the following as you can:

- A description of the vulnerability and its impact.
- Steps to reproduce, or a proof of concept.
- The affected file, endpoint, or component.
- Any suggested fix, if you have one.

## What to expect

- An acknowledgement of your report, normally within a few business days.
- An assessment of the issue and, if confirmed, a fix on `main`.
- Credit for the discovery if you would like it, once a fix is released.

Thank you for helping keep the project and its users safe.
